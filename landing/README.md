# Static landing page

`index.html` is the standalone static product page. It is separate from relay
admission and owned HTTPS carrier behavior; serving it does not start AEGIS.
Open the file locally for content review or serve it with an approved static
hosting process. Do not add private access material to page source.

Product claims should agree with the root [README](../README.md). Branding lives
in [assets](../assets/README.md); documentation changes preserve image bytes.

The page describes a controlled Linux beta with private material for approved
test hosts. It does not publish population/infrastructure counts or offer a
public package download. Its source-guide link is relative to the repository;
a static host must make that document available or supply the matching approved
documentation URL. Stable/native acceptance and all security findings remain
open within their stated scopes. Workspace metadata declares `MIT OR Apache-2.0`;
the [MIT](../LICENSE-MIT), [Apache-2.0](../LICENSE-APACHE) and [NOTICE](../NOTICE)
files describe source licensing; signed binary notice/license acceptance remains
separate and open.
