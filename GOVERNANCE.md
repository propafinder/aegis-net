# Project governance

AEGIS is maintained by the repository owner. The maintainer decides project
scope, reviews and merges pull requests, and is responsible for releases.

## Decisions and review

Changes are proposed through pull requests with reproducible checks and an
honest description of their limitations. Automated assistants may propose and
implement changes; they do not replace human review of security conclusions.

Changes to the license, release process, privacy handling or security response
process are recorded in the repository with their date and scope.

## Evidence

Source checks, CI, native installed tests, field measurements and an external
audit are different kinds of evidence. A result belongs to an exact source
commit and build; a later change needs its own checks.
