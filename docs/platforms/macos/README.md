# macOS

The macOS client is the NetworkExtension package in
[tools/macos/aegis-network-extension](../../../tools/macos/aegis-network-extension/README.md):
a menu-bar containing app and a Packet Tunnel system extension. A separate
utun lab ([design](macos-utun-lab-design.md)) and the client's
[macos_tunnel](../../../aegis-client/src/macos_tunnel/README.md) worker are
development paths.

- [User guide](user-guide.md): installing the app, approvals, joining with an
  invitation, connecting, states and diagnostics
- [Install, enable and enroll](install-and-enable.md): approvals, host
  commands, online enrollment and identity import
- [Operate](operate.md): day-to-day commands, renewal and logs
- [Troubleshooting](troubleshooting.md): symptoms, causes and fixes

Signing requires your own Apple Developer Team ID; see the package README.
