# Laboratory modules

main.rs routes only the six declared bounded CLI model actions and build-info/help. The previous synthetic demo aggregation is omitted from this entrypoint; lib.rs retains the original offline model APIs and controlled fixtures. research_topology reexports shared core graph algorithms; research_channel/research_covert_channels/research_stream cover declared mathematical inputs.

### Contracts and limits

https_bridge has a real controlled TLS/H2 path; message_carrier uses Tokio channels, mediated_route models attested service routing, and ephemeral_ingress models rotation. These are distinct from deployed Snowflake, SFU or cloud functions. Pure model results must retain their assumptions.

### Entry points and maintenance

causal_queue/full_flow model service/flow composition; fleet_inventory/dependency_cuts consume declared resources; deferred_cover and nonstationary model specific experiments. Follow the parent detailed README for input bounds and limitations.
