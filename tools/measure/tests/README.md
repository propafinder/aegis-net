# Paired private operator regressions

Integration tests launch actual aegis-measure child processes for private control, Poisson insertion and Poisson timing with synthetic private identities and explicitly owned localhost applications.

### Contracts and limits

A successful local exchange checks the CLI lifecycle, payload/counter contract and owned teardown. Controlled deterministic input does not establish legitimate Poisson cover, M/M/1 service, target-network behavior or cross-platform timing guarantees. A typed refusal is not positive delivery.

### Entry points and maintenance

Read each fixture’s READY observations, original deadlines and owned child cleanup before changes. support/ contains test-only timing/refusal diagnostics; no real device credentials belong in fixtures.
