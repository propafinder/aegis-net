# Windows kernel driver sources

The aegis-wfp directory contains the controlled Windows Filtering Platform redirect proof and its Visual C++ project/INF metadata.

### Contracts and limits

The controlled IPv4 TCP redirect proof is separate from the supported Rust client full-host lifecycle. Do not infer UDP, DNS, IPv6 or production signing from a kernel callout compiling.

### Entry points and maintenance

The companion userspace controller is tools/windows/aegis-wfpctl. Read both source scopes before a deliberately authorized driver test.
