# aegis-core/src/bootstrap_launcher

Regression tests for the authenticated onboarding launcher generated by the parent bootstrap_launcher.rs module.

## Contract

Public release pins come from an independently trusted local profile. Tests cover validation and launcher behavior using synthetic release material; a fetched mirror must never become the source of its own trust pins.

## Key files

- [tests.rs](tests.rs)

The enclosing module is [bootstrap_launcher.rs](../bootstrap_launcher.rs); this directory contains its split implementation or test modules.

## Development and checks

Run from the repository root:

```sh
cargo test --locked -p aegis-core --lib bootstrap_launcher
```

The filter names the enclosing module; feature and OS gates can exclude its tests. Confirm the expected tests are present on the supported target.

For dependency features and launch procedures, see [aegis-core](../../README.md).
