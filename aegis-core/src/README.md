# aegis-core/src

Public library implementation and the re-exports consumed by native runtimes and tools.

## Contract

Start at lib.rs, then follow the actual module declarations: many modules own a same-named subdirectory. Settings validation, transport policy and secret-file custody are shared admission boundaries. Keep data-only models separate from adapters that mutate native state.

## Directories

| Directory | Responsibility |
| --- | --- |
| [bootstrap_launcher/](bootstrap_launcher/README.md) | Regression tests for the authenticated onboarding launcher generated by the parent bootstrap_launcher.rs module. |
| [brain/](brain/README.md) | Adaptive strategy ordering, observations, failure beliefs, health, probing and explanations for direct connections. |
| [platform/](platform/README.md) | Cross-platform installation layout vocabulary, currently containing the Windows layout implementation. |
| [protocols/](protocols/README.md) | TLS handshake parsing and editing, JA3/JA3S helpers and limited QUIC Initial inspection. |

| [secure_channel/](secure_channel/README.md) | Independent TLS 1.3 device channel, bounded control/datagram framing, enrollment, registry freshness and paired experimental shaping. |
| [shield/](shield/README.md) | Startup sentinel heuristics and repeating-key XOR environment-string decoding (obfuscation, not encryption). |
| [signals/](signals/README.md) | Connection outcome classification and runtime metric vocabulary consumed by Brain. |
| [state_secret/](state_secret/README.md) | The explicit storage backend for encrypted Brain-state keys. |
| [state_v2/](state_v2/README.md) | Runtime state schema and asynchronous batched persistence. |
| [strategies/](strategies/README.md) | Direct-mode first-buffer strategies and the capability-aware send interface. |
| [traffic_privacy/](traffic_privacy/README.md) | Experimental finite framing, cover coding, pacing, rate-distortion models and bounded stream consumers. |
| [tunnel/](tunnel/README.md) | Fresh legacy protocol module and its local fixture directory beneath tunnel.rs. |
| [windows_tunnel/](windows_tunnel/README.md) | Windows Wintun loading, owned routes, persistent WFP protection and tunnel lifecycle ownership. |

## Development and checks

Run from the repository root:

```sh
cargo test --locked -p aegis-core --lib
```

The filter names the enclosing module; feature and OS gates can exclude its tests. Confirm the expected tests are present on the supported target.

For dependency features and launch procedures, see [aegis-core](../README.md).
