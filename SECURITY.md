# Security policy

AEGIS is beta software without a stable release, and no external audit covers
the current source.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository ("Report a vulnerability"
on the Security tab). If that is unavailable, open a public issue that asks
for a private contact without including any details.

Include the exact commit or package, platform, feature profile and a minimal
reproduction. Do not send relay tokens, device keys, invitation files or other
people's traffic.

## Handling

Reports are acknowledged as soon as practical. Fixes are developed privately
where needed and disclosed after a fix is available, with timing agreed with
the reporter. There is no bug bounty and no fixed response-time commitment.

Only the latest commit on `main` is supported.
