# Lua examples

`example.lua` and `order_example.lua` illustrate optional direct strategy order
and chunk customization. The `lua` Cargo feature and explicit client configuration
control use; they are not loaded simply because these files are present.

Read the scripts and the client/core Lua configuration before selecting one.
They do not authorize raw packet strategies or prove on-wire evasion.
Parent: [assets](../README.md); runtime: [core](../../aegis-core/README.md).
